3
Fill In Student Data

Follow these rules for every row to avoid validation errors.

  • All six columns are mandatory for every row: Email, Contact, NIELIT Centre, Batch Code, Full Name, Gender.
  • Email must be a valid, unique address — not already registered.
  • Contact must be a unique 10-digit number.
  • NIELIT Centre must exactly match a centre name already created in Manage Centres — check the template's "Valid Centres" sheet.
  • Batch Code is automatically uppercased and stripped of spaces (e.g. "batch 26 a" → "BATCH26A").
  • Gender must be Male, Female, or Other.
If any row fails validation, no accounts are created — fix all errors shown and re-upload.
